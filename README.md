## 一、这是什么

刷测评区总会怀疑：这期「横评」到底是真体验，还是冠军早就内定了？

诚实豆沙包是一个 Chrome 扩展。打开任意 B 站视频，点一下右上角的包子，它会：

1. 抓取当前视频的字幕、标题、UP 主、简介、置顶评论、相关视频列表；
2. 交给大模型做**两路一审**——先让「卷宗官」做四个思想实验（平行宇宙比对、倒推沉默、缺点过秤、生活感浓度），再让「判官」对照判例定档；
3. 输出 S / A / B / C 四档情商指数（**情商越高，恰饭越浓**），并给出精确到时间点的「嘴替」翻译，点击直接跳转原片对应位置。

整个过程约 20 秒。所有数据只在你自己的浏览器里处理。

## 二、安装

本版本为 GitHub 开源版，通过「加载已解压的扩展」安装：

1. 下载并解压 `【诚实豆沙包v10.4.9-github】诚实豆沙包.zip` 到一个固定目录（别放临时文件夹，删了扩展就废了）；
2. 浏览器地址栏输入 `chrome://extensions`，打开右上角「**开发者模式**」；
3. 点「**加载已解压的扩展程序**」，选择刚才解压的目录；
4. 打开任意 B 站视频页，右上角出现包子浮窗即成功。

> 建议同时固定扩展：点浏览器工具栏拼图图标，把「诚实豆沙包」📌 固定住，方便打开侧边栏。

## 三、配置 API Key（必需）

开源版**不内置任何共享 Key**，需要自备一家大模型服务商的 API Key：

1. 点包子浮窗 →「API 设置」（或浏览器侧边栏打开面板）；
2. 选择服务商，默认 **DeepSeek**（按量计费，单次鉴定成本极低），也兼容 OpenAI / Anthropic / Google Gemini / 阿里 Qwen；
3. 到对应官网创建 Key（DeepSeek：platform.deepseek.com → API Keys → 创建），粘贴进输入框，点「保存」；
4. 可点「测试连通」确认生效。

安全说明：Key 仅保存在你浏览器的本地存储（chrome.storage），由你的浏览器**直连**服务商官方域名，不经过任何第三方服务器（包括作者——作者没有服务器）。自定义 Base URL 仅限各服务商官方域名白名单，防止 Key 被发送到第三方。

## 四、日常使用

- **开始鉴定**：打开 B 站视频页 → 点包子 → 等约 20 秒出结果；
- **拖动包子**：按住包子浮窗可以拖到屏幕任意位置，位置会记住；
- **侧边栏**：点浏览器工具栏的扩展图标打开侧边栏面板，适合对照视频细读判词；
- **时间轴跳转**：结果里的时间点（如 03:12）点击即跳转播放器；
- **换视频**：刷到下一个视频自动重置，点新视频的包子重新鉴定；
- **重新鉴定**：同一视频的结果会缓存，避免重复扣费。

## 五、档位怎么看

| 档位 | 含义 |
|---|---|
| **C** | 清白——真实使用体验，优点缺点一起讲 |
| **B** | 基本可信——内容大体客观，偶有倾向；有合作痕迹但缺点讲到了实处 |
| **A** | 情商偏高——立场与厂商观点非常接近 |
| **S** | 恰饭浓度拉满——暗戳戳横评拉踩、赛制定制、剧本痕迹实锤 |

判 B/C 时附固定寄语：「请大大方方一键三连，这会对up有很大的帮助！」——恰饭不是罪，藏着掖着才是。

## 六、隐私与数据

- 无账号系统、无遥测、无统计、无广告、无追踪；
- 仅在你主动点击鉴定时读取当前视频页的公开信息（标题、UP 主、字幕、评论、相关视频）；
